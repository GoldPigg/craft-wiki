# 用户指南

## 如何阅读和查阅

本站按“地区—省份—门类—项目”四级组织内容，左侧目录树可逐级展开：先选地区（北方、东部、南方、西部），再选省份，省份下的「简介」是其索引页，「传统技艺」等门类下则是单个项目。项目页右侧会生成页内目录，点击标题旁的 `#` 可复制锚点。若想按门类浏览，可先读[项目分类说明](/wiki/intro/classification)。

每个项目页开头是一段概述，随后是配图与图注，再往下依次是「历史源流」「技艺特征（或艺术特征）」「传承与保护」「相关条目」。

## 如何修改条目

内容全部是 `content/wiki` 下的 Markdown 文件，路径与侧边栏结构一一对应。

- 改文字：打开对应项目页，直接修改正文；请保留 frontmatter 与图片块，改完把 `updatedAt` 更新为当天日期。
- 加项目：新建 `content/wiki/<地区>/<省份>/<门类>/<项目>.md`，正文按“一级标题 + 概述 + 图片块 + 四节”的顺序写；配图放到 `public/images/<地区>/<省份>/<门类>/`；再到 `content/wiki.config.ts` 的对应门类下登记一行，并在省份索引页补上条目与摘要。
- 换图片：把新图覆盖到 `public/images/...` 下同名文件即可；若换图，请同步更新图注里的作者与许可。
- 结构有变：新增省份或门类时，除上述文件外，还要更新地区导览页与省份索引页。

写作时以有共识的通识内容为主，年份、批次、传承人、数量等信息尽量核实；拿不准的照片宁可不用，也不要配错。
